# Лабораторная работа № 1 — труба и компрессорная станция

Консольная программа хранит одну трубу и одну КС. Повторное добавление заменяет соответствующий объект. Интерфейс на английском, как разрешено заданием. Названия могут содержать пробелы.

## Запуск

Открыть `anisimov_Lab1.slnx` в Visual Studio 2022, выбрать Debug / x64 и нажать Ctrl+F5. Нужны средства разработки C++ и MSVC v143 версии 14.44.35207 (установлены на этом компьютере). В проекте сохранён C++20; код использует возможности C++17.

Меню: 1 — добавить трубу; 2 — добавить КС; 3 — просмотр; 4 — изменить ремонт; 5 — запустить или остановить один цех; 6 — сохранить; 7 — загрузить; 0 — выход. Закрытие ввода также завершает программу.

## Устройство кода

Все функции находятся в `anisimov_Lab1/anisimov_Lab1.cpp`:

- `Pipe` и `CompressorStation` содержат только поля объектов.
- `AppState` содержит объекты и внешние флаги `hasPipe`, `hasStation`.
- `readNumberLine` проверяет одну строку целиком; `readNumber` повторяет консольный запрос при ошибке. `readName` читает название с пробелами.
- `addPipe`, `addStation`, `showPipe`, `showStation`, `editPipe`, `editStation` отвечают за консольную работу.
- `savePipe`, `loadPipe`, `saveCompressorStation`, `loadCompressorStation` работают только с полями через потоки и возвращают `bool`. Они не открывают файлы, не записывают количество и не выводят сообщений.
- `saveToFile` и `loadFromFile` открывают файлы, обрабатывают количество объектов и сообщают причины ошибок. Загрузка сначала заполняет временный `AppState` и меняет текущие данные только после полного успеха.
- `main` содержит меню и состояние; глобальных переменных нет.

## Формат файла

Каждое значение занимает отдельную строку:

```text
pipeCount (0 или 1)
[название трубы]
[длина в км]
[диаметр в мм]
[ремонт: 0 или 1]
stationCount (0 или 1)
[название КС]
[всего цехов]
[цехов в работе]
[класс станции]
```

Поля в квадратных скобках присутствуют только при количестве 1; сами скобки в файл не пишутся. При отсутствии объектов файл содержит две строки: `0` и `0`. Лишние строки и поля отклоняются. Последняя строка может не завершаться переводом строки.

**По дополнительному ТЗ сохранение работает только с уже существующим файлом.** Введите путь без кавычек. Отсутствующий файл программа не создаёт. Для первой проверки загрузите `examples/both.txt`; для сохранения используйте заранее созданную копию этого файла. Сохранение перезаписывает содержимое выбранного файла.

Четыре примера: `examples/empty.txt`, `examples/pipe-only.txt`, `examples/station-only.txt`, `examples/both.txt`. Пути отсчитываются от рабочей папки программы; при запуске из Visual Studio надёжнее указать полный путь.

## Проверка ограничений

Название непустое; длина конечная и строго больше нуля; диаметр, число цехов и класс — целые положительные числа; цехи в работе — от нуля до общего количества. Количество объектов и ремонт — только 0 или 1. Отклоняются переполнение, дробное значение в целочисленном поле, текст после числа, NaN/Infinity, пустые и обрезанные файлы. Ошибка загрузки сохраняет прежнее состояние, успешная загрузка нулевого количества сбрасывает соответствующий объект.

## Проверки

В PowerShell из папки репозитория: `./tests/run-tests.ps1`. Скрипт собирает программу и отдельные тесты, проверяет 41 случай для файлов и ввода, а также 8 консольных сценариев. Временные файлы создаются в отдельной папке `%TEMP%`, пользовательские данные не затрагиваются.

Проверено на этом компьютере: сборки Debug/x64 и Release/x64; тестовый проект с уровнем предупреждений W4 и предупреждениями как ошибками; 41 проверка файлов/ввода и 8 сценариев консоли.
